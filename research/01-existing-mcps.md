# 01 — Existing hotel / stay / travel MCP servers (India focus)

Researched 2026-10-05. Constraints: personal/team use, self-hosting OK, **free tiers only**, **live price + availability required**, India coverage, geo search (station / airport / landmark / lat-long + radius).

Legend: **[V-live]** = I called the server myself with a live India query (New Delhi Railway Station, 28.6430,77.2194, 2026-11-10→11, 2 adults). **[V-src]** = verified by reading the repo / tool schema (`tools/list`). **[U]** = unverified (from docs / third-party listings only).

**Verdict:** a thin wrapper around a paid SaaS; free tier is a trial, no radius search, nothing to self-host. Not a fit.

## 3. Notes

- **Live test snapshot (NDLS, 1 night, 2 adults):** trivago → 25 hotels, INR, 0.2–2.4 km, cheapest ₹10.6k (premium-skewed). HotelsCasa → 10 hotels 0.1–0.2 km, €21–€95, availability confirmed. Stayker → INR totals from ₹4k. FareEagle → 50 Delhi hotels from ₹1,430 (no coordinates). TourMind → 1 hotel, CNY. Bluepillow → 19 properties, no parseable prices. VistaLink → 5 near-station hotels, no prices without key.
- **No server does the whole job.** None offers "compare distance to next day's departure point" or multi-city itinerary logic; at best they return hotel lat/lng, so distance/route logic must be built (or composed with a geo/routing MCP).
- **Radius control is rare.** Explicit radius: HotelsCasa, bluepillow, TourMind, Stayker, VistaLink, places-mcp (and LiteAPI upstream). trivago takes a point but no radius. RollingGo uses POI + `distanceInMeter` with native `train_station` / `airport` place types.
- **Currency:** only trivago, Stayker and FareEagle returned INR; HotelsCasa EUR only; TourMind/RollingGo CNY-leaning.
- **Hosted ≠ self-hostable.** All the free + live + India options are third-party hosted endpoints with no SLA. Self-hostable live-price options are scrapers/unofficial (stays, openbnb, hotelrate-crawl) or keyed APIs (SerpApi 250/mo, LiteAPI sandbox).
- **Trust/safety:** several hosted servers (FareEagle, getmyhotels, Stayker, Maqami, TourMind) expose booking/payment/cancel tools — a wrapper should whitelist read-only tools. trivago's tool result includes a prompt-style `system_message` instructing the model how to format output — treat as data, strip in a proxy.
- **Dead/closed:** Amadeus Self-Service (shut 2026-07-17); Booking.com Demand API (managed affiliates only, AI use needs written approval); Expedia B2B MCP not yet public.

## 4. Ranking for this brief (free + live + India + geo)

1. **trivago official MCP** — free, no key, live INR prices from Indian OTAs (incl. MakeMyTrip), lat/lng search. Gaps: no radius/price sort, premium-skewed, heavy payload.
2. **HotelsCasa MCP** — free, no key, true lat/lng+radius, live availability, budget inventory in India. Gaps: EUR only, small vendor.
3. **RollingGo/DIDA** — free key, unlimited, `train_station`/`airport` POI search with distance. Gap: India coverage/currency not yet verified (needs key).
4. **Stayker** / **bluepillow** — geo radius + live INR (Stayker) / strong geo API (bluepillow); each has a data gap (no coords / no prices in test).
5. **him229/stays** (self-hosted Google Hotels) or **SerpApi** (250/mo) as a backup live-price source; **FareEagle** for India-native budget pricing by city.
